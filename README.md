# Connecting the Dots 🔵

> *Место где твои мысли дают результат — 
> где точки соединяются и всё становится ясным*

## Что это?

Connecting the Dots — это не просто игра в Четыре в ряд. 
Это инструмент для людей с overthinking. 
Каждая фишка — это мысль. Каждый ход — это решение. 
Четыре в ряд — это ясность.

## Для кого?

Молодые взрослые 20–35 лет: предприниматели, студенты, 
все кто знает что такое тревожность и переизбыток мыслей.

## Почему это ценно?

Большинство игр — просто игры. Эта — тренирует ум 
и дарит момент покоя. После каждой партии AI Коуч 
анализирует твои ходы и показывает Индекс ясности.

## Функционал

- 🤖 ИИ противник — 3 уровня сложности
- 🧠 AI Коуч — анализ ходов после партии  
- 💭 Подсказка со стоической цитатой
- 🏆 Победные фишки превращаются в золото
- 📜 Цитаты меняются каждый ход
- 📱 Адаптивный дизайн для мобильных
- ✦ Upgrade to Pro — модель монетизации

## Бизнес-модель

- Free: игра против ИИ, базовые функции
- Pro $4.99/мес: дневник мыслей, глубокий
